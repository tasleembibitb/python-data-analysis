# Python Data Analysis — Shop Sales (Demo)

Analysis of **100 sample orders (Jan–Jun 2026)** from a small Sukkur boutique, using pandas and matplotlib. The dataset is **sample / demo data generated for practice** — it is not real business data. It pairs with the [Modern Landing Page](../modern-landing-page/) demo shop (same fictional "Noor Boutique" products).

## What the script does

`analysis.py`:
1. Loads `sales_data.csv` with pandas
2. Calculates total revenue, average order value, and total items sold
3. Ranks products by revenue and by quantity sold
4. Breaks revenue down by city and by payment method
5. Shows the monthly revenue trend (Jan–Jun 2026)
6. Saves two charts: `revenue_by_product.png` and `monthly_revenue.png`

## Findings (from this sample data — run the script to reproduce)

- **100 orders**, total revenue **Rs. 432,816**, average order **Rs. 4,328**, **184 items** sold
- **Top product by revenue:** Eid Special 3-Piece (Rs. 179,964) — highest price, so it leads on revenue; Embroidered 3-Piece is second (Rs. 132,962)
- **Top product by items sold:** Embroidered 3-Piece (38 items), followed by Eid Special 3-Piece (36 items)
- **Top city by revenue:** Shikarpur (Rs. 111,157), followed by Hyderabad (Rs. 87,670); Sukkur is 5th (Rs. 47,978)
- **Top payment method:** Bank Transfer (Rs. 143,736), followed by JazzCash (Rs. 115,157); Cash on Delivery is third (Rs. 104,851)
- **Best month:** April 2026 (Rs. 113,857); monthly revenue is uneven — Jan Rs. 67,769, Feb Rs. 55,772, Mar Rs. 82,274, Apr Rs. 113,857, May Rs. 44,976, Jun Rs. 68,168 — with an April peak and a May dip

> These numbers describe the sample dataset only. Re-run the script after editing the CSV and the findings will update.

## Dataset

`sales_data.csv` — 100 rows, 8 columns:

| Column | Meaning |
|---|---|
| order_id | Order number (1–100) |
| date | Order date (2026-01-01 to 2026-06-28) |
| product | Product name |
| unit_price_pkr | Price per item in PKR |
| quantity | Items in the order (1–3) |
| total_pkr | unit_price × quantity |
| city | Customer city (Sukkur, Karachi, Larkana, Hyderabad, Khairpur, Shikarpur, Jacobabad) |
| payment_method | Cash on Delivery, Bank Transfer, JazzCash, EasyPaisa |

## Skills used

Python, pandas (groupby, aggregation), matplotlib (bar + line charts), CSV data handling

## How to run

```bash
pip install -r requirements.txt
python analysis.py
```

Output: summary printed in the terminal + two PNG charts in this folder.
